About

CrashReporter collects crash information and helps you send useful reports to developers. This TXT build is maintained by physmathdev.

TXT export — added by physmathdev

The TXT button on the crash details screen was added by physmathdev. It saves the crash log and syslog as .txt files to:

/var/mobile/Documents/CrashReporter

After saving, a share sheet opens so the files can be sent anywhere.

Install

  1. Add the source below in Cydia, Sileo or Zebra.
  2. Search for CrashReporter TXT and install it.
Add to Sileo Add to Cydia

Requirements

iOS 4.0+ and the original CrashReporter dependencies: MobileSubstrate, PreferenceLoader, libcrashreport, libpackageinfo and techsupport.
