oldtube

Version 1.0.0 · physmath
iOS 5.0 – 10.x Tweaks iphoneos-arm Free

About

oldtube keeps the classic Google YouTube app working without a backend server. It supports YouTube 1.0.0 through 1.4.0 and 2.0.0 through 2.2.0 on iOS 5 through iOS 10, and restores sign-in, the signed-in home feed, subscriptions, personal recommendations, search history and watch history.

There is no analytics, crash reporting or telemetry.

What's new in 1.0.0

  • Endless personal recommendations. The “What To Watch” feed keeps loading related videos instead of stopping after the first page, and it never falls back to global trending results.
  • Normal watch history. Watched videos are recorded through the app's playback tracking and appear in the History tab, with paging for older entries.
  • YouTube 2.2.0 support. The tweak now covers all 2.x versions, including 2.1.0 and 2.2.0.
  • Bundled n/sig solver. Playback signatures work offline, with an automatic weekly refresh when the solver is updated.
  • Persistent search history. Recent searches survive app restarts.
  • New identity. A new name, a new retro-TV icon and a cleaned-up preferences panel. Analytics, crash reporting and debug mail are gone.

What it does

  • Fixes Google sign-in so accounts can be added again
  • Restores the signed-in home feed and personal recommendations
  • Loads subscription uploads, favorites, watch later and uploaded videos
  • Keeps watch history and search history between launches
  • Handles feed paging without crashes or duplicate rows
  • Provides preferences for playback quality and feed behavior

What doesn't work

  • Purchases
  • Age-restricted content in some regions
  • The Add Channel button, which opens a channel list with no sensible default

Install

  1. Add the source below in Cydia, Sileo or Zebra.
  2. Search for oldtube and install it.
  3. Respring the device.
Add to Sileo Add to Cydia

Installing oldtube replaces the previous package automatically, so existing settings and history are kept.

Requirements

Jailbroken iOS 5.0 – 10.x with MobileSubstrate and PreferenceLoader. Supported YouTube versions: 1.0.0, 1.0.1, 1.1.0, 1.2.1, 1.3.0, 1.4.0, 2.0.0, 2.1.0 and 2.2.0.
