About

oldtube is a full YouTube client for iOS 5–10, built on the classic Google YouTube app — 2.0.0 on iOS 7–10 and 1.4.0 on iOS 5–6. It runs without a backend server of its own.

It gives you the complete experience: sign-in with your Google account, the signed-in home feed, subscriptions, personal recommendations, search, channels, playlists, comments, subtitles, background playback and an in-player quality menu up to 1080p — plus a light/dark theme.

The one major feature that does not work right now is watch history. It is not fixed in this release and is not claimed as a feature.

Because the sign-in browser differs between the two OS ranges, oldtube ships as two packages:

  • oldtube (com.physmath.oldtube) — iOS 7.0 – 10.x.
  • oldtube (iOS 5–6) (com.physmath.oldtube.ios6) — iOS 5.0 – 6.x.

Both packages include LightKit, the embedded modern browser that Google sign-in runs in, so there is no separate LightKit package to install any more. Install the package that matches your iOS version; the two conflict, so only one is present.

There is no analytics, crash reporting or telemetry.

What's new in 1.6.6 (iOS 7–10)

  • The in-player settings menu now works. In 1.6.5 the sheet that holds quality and subtitles dismissed itself as soon as you tapped a row: the tap catcher that closes the menu on the dimmed background also swallowed the taps on its own rows. Rows now receive their taps, so Качество opens the quality list and Субтитры raises the app’s own subtitle picker, while a tap on the background still closes the menu.
  • Clearer menu labels. The two entries are now written Субтитры and Качество instead of all-caps.

What's new in 1.6.5 (iOS 7–10)

  • Dark theme covers the last light surfaces. The strip under the video (the share / add-to action bar), the Subscribed button and the search-suggestions popover were still loaded as plain white artwork, so they stayed bright under the light text. They are now recoloured through the dark palette, and their grey glyphs (“add to”, share, and the popover’s “Варианты” header) flip to a light tone so they stay readable. The light theme is untouched; the iOS 5–6 package is unchanged.
  • One gear for quality and subtitles. The separate CC button is folded into the player’s gear button. Tapping the gear now opens a single settings sheet with СУБТИТРЫ (which raises the app’s own subtitle picker) and КАЧЕСТВО (the Авто / 1080p / 720p / 360p / 240p / 144p list), so the whole playback menu lives in one place instead of being split across two buttons.

What's new in 1.6.4 (iOS 7–10)

  • Dark theme completed on the remaining surfaces. The comment cell background, the channel page’s top bar and default banner, the tab-title bar and its separator, and the thumbnail placeholder are loaded as plain images rather than as image views, so 1.6.3’s view-based fix left them light. They are now recoloured through the palette while the dark theme is on. The iOS 5–6 package is unchanged.

What's new in 1.6.3 (iOS 7–10)

  • Fixed the dark-theme contrast bug. The iPad feed — and the other list and card screens — painted their cards and the video “meta” panels with light built-in images, so the light-grey titles and view counts sat on white cards. Those image-backed surfaces now use the dark card colour while the dark theme is on, so the feed is readable again.
  • Finished the dark theme for the 2.0.0 UI. Feed and list cells now ask for the app's own dark card artwork, and the grouped-table cards, section headers, suggested/related cells, GoogleKit grey surfaces and separators all follow the dark palette. iPad titles now use the light palette too. The iOS 5–6 package is unchanged.

What's new in 1.6.2 (iOS 5–6)

  • Fixed the playback error after changing quality. On YouTube 1.4.0 the player used to trim its SABR adaptive ladder down to the chosen height. That could leave playback negotiating with a partial format list and showing “playback error” on the next video. The full ladder now stays intact and the choice is applied as a playback hint instead, so video starts reliably at the selected quality (or the closest one the video actually offers).

What's new in 1.6.1 (iOS 5–6)

  • The player quality gear is back on iOS 5–6. YouTube 1.4.0 uses a different player controls view, so the in-player gear from the iOS 7–10 package did not appear after the move to 1.4.0. It is now added to the 1.4.0 player bar, in the same place next to the CC button, with the same Авто / 1080p / 720p / 360p / 240p / 144p sheet. The choice is applied to the SABR stream the next time a video is opened. The iOS 7–10 package is unchanged.

What's new in 1.6.0

  • iOS 5–6 now uses YouTube 1.4.0. The iOS 5–6 package bundles the classic YouTube 1.4.0 app instead of 2.0.0. 1.4.0 is the version oldtube was originally built for, and it replaces the 2.0.0 payload previously shipped on iOS 5 and 6.
  • LightKit is bundled into both packages. The embedded sign-in browser is now installed by oldtube itself on both iOS 5–6 and iOS 7–10. The separate com.physmath.oldtube.lightkit package is no longer needed and is removed automatically on upgrade.
  • iOS 7–10 payload is unchanged apart from those files. It still bundles YouTube 2.0.0 and the cropped icon.

What's new in 1.5.1-2 (iOS 7–10)

  • Home-screen icon cropped. The icon is now pre-cropped with transparent rounded corners, so the red button fills the icon tile instead of sitting inside a dark square frame. Nothing else changed in the iOS 7–10 package.

What's new in 1.5.2-1 (iOS 5–6)

  • Fixed the iOS 5–6 launch crash. The dark theme set a tab-bar style that only exists from iOS 7 on; on iOS 5/6 that raised an exception and closed YouTube during startup. It is now applied only where the API exists, so the app launches normally on iOS 5 and 6.
  • Home-screen icon fixed for iOS 5–6. Those systems do not apply the iOS 7 rounded icon mask, so the icon is now pre-cropped with transparent rounded corners instead of showing a dark square background.

What's new in 1.5.1-1

  • The light/dark switch is now easy to find. It sits at the very top of Settings → oldtube, in a new Appearance group, instead of being buried in Misc Settings.
  • There is also a switch inside YouTube. The app's own Settings screen (Settings → Dark Theme) now has the same row. Tapping it flips the setting and restarts YouTube so the theme applies; the system-Settings switch and the in-app switch read and write the same preference.
  • The preferences page refreshes on install. Installing this version restarts the Settings app, so the new Appearance section shows up right away.

What's new in 1.5.1

  • Light/dark switch. Settings → oldtube → Misc Settings → Dark Theme turns the dark theme on or off. The choice is applied the next time YouTube starts; flipping the switch closes YouTube so it reloads with the new theme.
  • Dark theme readability fixed. Text was too dim in 1.5.0 and, especially on iPad, the navigation bar and feed cards kept their light backgrounds under light text. The palette is brighter now, and those surfaces are forced dark, so titles, guide entries and feed metadata are readable everywhere.
  • Quality gear placement fixed again. On wide screens the gear now sits in the free space just left of the total-time label; on narrow screens it falls back to the classic slot between the time and the CC button and moves the time label over. It no longer covers “11:57”.

What's new in 1.5.0

  • Dark theme. The whole app — feeds, lists, cards, player chrome and the navigation bars — now uses a proper dark palette with light text. It is on by default and can be switched off in Settings → oldtube → Misc Settings → Dark Theme (relaunch YouTube after changing it).
  • 1080p quality option. The in-player quality menu now offers 1080p, for streams whose adaptive ladder actually advertises it. On videos that only go up to 720p, picking 1080p simply plays the best available.
  • The app is now called oldtube. The home-screen icon is the oldtube icon instead of the stock YouTube one, and the name under it is oldtube.
  • A proper launch screen. While the app starts you now see a dark screen with the oldtube wordmark instead of the stock YouTube splash.

What's new in 1.3.1

  • Sign-in no longer crashes on iOS 7–10. The embedded sign-in browser's JavaScript engine was trying to use its JIT compiler, which faults on these systems a couple of seconds after Google's page loads and takes YouTube down with it. It now runs in the interpreter, so the page loads and submits normally on iOS 7, 8, 9 and 10.

What's new in 1.3.0

  • Google sign-in now works on iOS 7–10 too. Sign-in runs in an embedded modern browser instead of the system web view, which Google refuses to authenticate. That browser is now bundled as a shared package for every supported iOS version, so sign-in works on iOS 5, 6, 7, 8, 9 and 10 alike.
  • Two packages instead of one. iOS 5–6 and iOS 7–10 are built and packaged separately, with the right browser for each range. The iOS 7–10 package upgrades existing installs seamlessly.
  • The player quality gear no longer overlaps the time. The gear sits between the elapsed/total time and the subtitles (CC) button. The total-time label ("1:10" and similar) is shifted left by exactly the room the gear needs — including in landscape and while playback keeps refreshing the label — so nothing is covered any more.
  • Honest descriptions. The claim that watch history works has been removed. History is not being fixed in this release.

Earlier fixes still included

  • Playback no longer freezes after the first minute or two. The player now locks on to the exact format it is playing, so YouTube can no longer switch to a format the local stream cannot serve.
  • Playback no longer stalls when YouTube omits the selected formats. Formats are read from the media headers that actually arrive instead of being dropped.
  • Quality and subtitles in the player bar. A gear button opens a dark settings sheet with СУБТИТРЫ and КАЧЕСТВО; the quality list offers Auto / 1080p / 720p / 360p / 240p / 144p and ticks the active choice. Picking a height limits the adaptive stream ladder and takes effect the next time a video is opened.
  • Endless personal recommendations. The "What To Watch" feed keeps loading related videos instead of stopping after the first page.
  • Bundled n/sig solver. Playback signatures work offline, with an automatic weekly refresh.
  • New identity. The oldtube icon on the home screen, the oldtube name, an oldtube launch screen, a cleaned-up preferences panel, and no analytics or debug mail.

What it does

  • Sign in with Google and browse as yourself (iOS 5 through iOS 10)
  • Signed-in home feed with endless personal recommendations
  • Subscriptions, favorites, watch later and your uploaded videos
  • Search, channels and playlists
  • Comments, subtitles and an in-player quality menu up to 1080p
  • Background playback and a light/dark theme
  • Continuous feed paging without crashes or duplicate rows

What doesn't work

  • Watch history (not fixed in this release)
  • Purchases
  • Age-restricted content in some regions
  • The Add Channel button, which opens a channel list with no sensible default

Install

  1. Add the source below in Cydia, Sileo or Zebra.
  2. Search for oldtube and install the package for your iOS version — oldtube on iOS 7–10, or oldtube (iOS 5–6) on iOS 5–6. Cydia only offers the one that fits.
  3. Respring the device.
Add to Sileo Add to Cydia

The package installs the matching YouTube app (2.0.0 on iOS 7–10, 1.4.0 on iOS 5–6), the tweak and LightKit together. It replaces any previous oldtube package and keeps existing settings.

Requirements

Jailbroken iOS 5.0 – 10.x with MobileSubstrate and PreferenceLoader. The package bundles the matching classic YouTube app: 1.4.0 on iOS 5–6 and 2.0.0 on iOS 7–10.

  • iOS 7.0 – 10.x: install oldtube.
  • iOS 5.0 – 6.x: install oldtube (iOS 5–6).
