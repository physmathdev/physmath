About

AnimeGO is an anime streaming client for iOS 4.3 through 10.3.4. This build is repackaged from the signed IPA so it can be installed directly from Cydia, Sileo or Zebra.

Install from Cydia

  1. Add the source below in Cydia, Sileo or Zebra.
  2. Search for AnimeGO and install it.
  3. The app appears on the Home Screen after uicache runs.

Prefer sideloading? Download the IPA or install it over the air from Safari.

Requirements

Jailbroken iOS 4.3 – 10.3.4, uikittools. The app bundle is unsigned, so AppSync (AppSync Unified) is required to launch it, as usual for repackaged IPAs.
