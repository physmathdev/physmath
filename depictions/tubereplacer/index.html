TubeReplacer

Version 2.0.1-3 · physmath
iOS 5.0 – 10.x Tweaks iphoneos-arm Free

About

TubeReplacer brings the classic YouTube experience back to iOS 10 when the modern API no longer works. It fixes the broken Google sign-in flow and restores the signed-in home feed and subscriptions.

What it does

  • Fixes Google sign-in (AppleSpell) so accounts can be added again
  • Restores the signed-in home feed
  • Fixes subscriptions parsing
  • Adds preferences for quality and debug options

Install

  1. Add the source below in Cydia, Sileo or Zebra.
  2. Search for TubeReplacer and install it.
  3. Respring the device.
Add to Sileo Add to Cydia

Requirements

Jailbroken iOS 5.0 – 10.x, MobileSubstrate and PreferenceLoader. The package installs two tweak dylibs and a preference bundle.
